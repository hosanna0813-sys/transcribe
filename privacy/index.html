隱私權政策

最後更新:2026 年 7 月

本政策說明本服務(以下稱「本站」)如何蒐集、使用與保護你的資料,以及第三方廣告的運作方式。使用本站即表示你同意本政策所述之處理方式。

一、本站提供的服務

本站將你的音檔或 YouTube 影片片段,透過人工智慧轉換成逐字稿。分為三種使用方式:免登入的免費試用、登入後可儲值的付費版,以及自備 OpenAI 金鑰的進階版。

二、我們如何處理你的內容

  • 音訊與逐字稿:你上傳的音檔或指定的 YouTube 片段,會傳送至 OpenAI 進行語音辨識與校正。內容僅用於完成該次轉錄,處理完成後即從伺服器暫存區清除,不作其他用途。
  • 免費試用:為防止濫用,系統會記錄你的來源 IP 當日累計使用時間(僅供計算每日免費額度),不與轉錄內容綁定。
  • 登入 / 付費版:使用電子郵件登入(由 Supabase 提供驗證),我們會保存你的電子郵件、額度餘額與使用紀錄(日期、來源、長度、花費),供你查詢與對帳。
  • 進階版(自備金鑰):你的 OpenAI API Key 與偏好設定只儲存在你自己裝置的瀏覽器,不會上傳到本站伺服器。

提醒:涉及機密或個資的內容,請先確認符合你所屬單位的資安規範再上傳。

三、金流

付費儲值透過綠界科技(ECPay)處理刷卡 / 行動支付。你的完整卡號等付款資訊由綠界處理,本站不會取得或保存。本站僅收到綠界的付款結果通知以完成額度入帳。

四、第三方廣告(Google AdSense)

本站使用 Google AdSense 顯示廣告。相關說明:

  • Google 等第三方供應商會使用 Cookie,依你造訪本站與其他網站的紀錄放送廣告。
  • Google 使用廣告 Cookie 可讓其合作夥伴根據你的造訪放送廣告。
  • 你可以前往 Google 廣告設定 停用個人化廣告,或透過 www.aboutads.info 停用部分第三方供應商的 Cookie。
  • 更多資訊請見 Google 廣告與隱私權說明。

五、Cookie 與本機儲存

本站會在你的瀏覽器儲存少量資料(例如深色模式偏好、進階版的金鑰與設定),用以記住你的選擇。廣告相關 Cookie 由上述第三方供應商設定。你可隨時在瀏覽器清除這些資料。

六、你的權利

你可要求查詢、更正或刪除我們保存的帳號資料。如需協助,請透過下方信箱與我們聯絡。

七、政策更新

本政策可能因服務調整而更新,更新後將於本頁公告。
