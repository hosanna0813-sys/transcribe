壹

填入 OpenAI API Key

申請 API Key ↗ 儲值與帳單 ↗ 設用量上限 ↗

首次使用:先到「申請 API Key」註冊並建立一把 Key,再到「儲值與帳單」加值(最低 US$5);建議順手到「設用量上限」設定每月費用上限以防超支。

貳

選擇錄音檔與選項

點擊選擇檔案(可一次選多個),或將錄音檔拖曳到此處
支援 mp3 / m4a / wav / mp4 / webm 等;超過 25 MB 會自動切分後接續轉錄,會依清單順序合併
    參

    詞庫(自動儲存於此裝置)

    以逗號分隔,修改後自動記住,下次開啟直接帶入。可加「錯誤寫法→正確寫法」對照,例如:餘情→輿情。前段詞彙也會作為 Whisper 的辨識提示。

    逐字稿結果

    兩個分頁可切換對照;下載與複製皆以目前顯示的分頁為準。內容可直接在框內修改。

    注意:錄音與文字會傳送至 OpenAI 伺服器處理,涉及機密或個資的內容請先確認符合貴機關資安規範。API Key、詞庫與版面選擇僅儲存於你自己裝置的瀏覽器,不會上傳到任何伺服器。
